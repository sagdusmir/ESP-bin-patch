ESP Bin Patch

Patch secrets in an already-built .bin, repair ESP-IDF checksums, then install over USB with ESP Web Tools. Runs entirely in the browser — the firmware is not uploaded anywhere.

1. Firmware file

An app-only firmware.bin can still be patched and downloaded, but cannot be web-installed (that would overwrite the bootloader).

2. Replacements

auto tries UTF-8 text vs decoded Base64 (Home Assistant API key). utf-8 is literal text (SSID). hex and base64 decode first. Replacement must be the same length or shorter.

3. Chip family

Must match the board you will flash. Detected from the image header; override if needed.

4. Install

Chrome or Edge, over HTTPS (or localhost). Connect the board via USB, then install the patched image.

This browser does not support Web Serial. Open this page in Chrome or Edge. Web Serial requires HTTPS (GitHub Pages) or localhost.
